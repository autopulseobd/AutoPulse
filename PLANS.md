# AutoPulse public coordination

Current engineering priority: standard OBD2 session integration and adapter reliability, tracked by the scoped `devin-ready` issues and [DEVIN_BACKLOG.md](DEVIN_BACKLOG.md).

Implementation work remains coordinated with the private repository's current writer. Public issues are investigation and acceptance contracts; they do not establish that a defect is reproduced or that a mobile release is accepted.

English localization and signed Android artifacts follow their recorded prerequisites. Manufacturer-specific expansion remains deferred under `post-v1` until standard-OBD V1 acceptance.

This repository publishes documentation and issue-authoring tools. It has no application deployment or release workflow.
